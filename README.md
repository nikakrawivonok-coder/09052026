# КПК Зони — стилізований MVP

Це мобільний веб-додаток у стилі іржавого КПК для твоєї S.T.A.L.K.E.R.-подібної настільної гри.

## Як запустити

1. Розпакуй архів.
2. Відкрий `index.html` у браузері.
3. На телефоні краще завантажити папку на GitHub Pages / Netlify / будь-який простий хостинг.
4. Після відкриття додаток зберігає стан у браузері через localStorage.

## Що вже працює

- мобільний інтерфейс у стилі КПК Зони;
- вкладки: Стан, Оточення, Вороги, Журнал, Майстер;
- кидки для стрільби:
  - Точно: 1d20 +2, -1 набій;
  - Нормально: 2d20, -2 набої;
  - Черга: 3d20 -2, -3 набої;
- списання набоїв;
- журнал подій;
- анімації мерехтіння, scanlines/noise, радіаційний pulse, підсвітка активної вкладки;
- редагування стану персонажа;
- редагування сцени;
- редагування ворогів;
- редагування інвентарю;
- експорт/імпорт JSON;
- базовий service worker для офлайн-кешу після першого запуску.

## Обмеження MVP

Це локальна версія. Вона не синхронізує стан між твоїм телефоном і телефоном друга.

Наступний етап: онлайн-синхронізація, ролі Майстер/Гравець, окремі посилання для кожного гравця, база даних, Telegram-повідомлення.
